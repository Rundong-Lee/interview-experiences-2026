# 算法学习协作约定

- 本目录是长期算法学习库，覆盖整个秋招、春招和任意公司；字节仅为当前重点。用户用 Python 准备常规算法手撕。
- study.json 是唯一学习进度源，必须保留用户题目、笔记、代码、状态、练习历史。没有独立练习证据不得标记完成。
- 看板保持简洁：题库、频率、常用方法筛选、练习与总结。不要恢复“当前查看范围”或冲刺管理。旧 campaigns 字段仅兼容保留。
- 方法使用常见算法与数据结构术语，允许多标签；不要自创抽象分类。
- 用户已授权在本面经仓库的算法文件夹保存和同步学习内容。学习前检查 git status 并拉取（git pull --ff-only）；如有本地未同步记录先保留并处理，不能覆盖。
- 记录后验证 JSON 与学习证据，提交并推送本目录的相关学习改动。不要混入其他目录改动，不强推，冲突保留两边并处理。
- 运行服务时优先通过 /api/study 读取最新 revision 并 PUT，利用备份和冲突保护；不要覆盖正在编辑的状态。跨设备同步前关闭服务，拉取后重新启动并刷新。
- 来源频率是当前岗位/题型下 sourceKey 的去重数，不是独立面试数或命中概率。区分常规算法、工程实现、模型实现、题意缺失、口述和笔试；保留全部原文证据。
- backups、缓存、截图和临时文件不上传。不要另外上传简历或内部项目原始资料。
